# Issue 與資安發現留言 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Issue 詳情頁與 `/security` 每條發現可隨時留言；Close（→`resolved`）改兩段式、可選填備註，issue 的備註併入 Discord「已解決」討論串回覆。

**Architecture:** 兩張同構表 `issue_comments`／`security_finding_comments`（FK cascade、RLS 無 policy）。純函式驗證在 `src/core/comments.ts`；Store port 加讀寫方法（Supabase＋InMemory）。issue 的 close 備註經 `transitionIssue` 的新 option 寫入並帶進 `buildResolveReply`；資安 close 備註在 server action 內於條件更新成功後寫入。前端共用 `CommentThread`／`CommentForm`／`CloseWithNote` 三個元件。

**Tech Stack:** Next.js App Router（server actions、`useActionState`）、Supabase Postgres、Vitest、pnpm。

**Spec:** `docs/superpowers/specs/2026-11-25-comments-design.md`

## Global Constraints

- `src/core/**` 純函式：禁 I/O、禁 `Date.now`／`new Date()`。
- 新表 `alter table ... enable row level security;`，**不建 policy**。
- Schema：`supabase migration new comments` → 編輯 → `supabase db push` → `supabase db advisors --type security` → `pnpm db:types`。**禁 MCP `apply_migration`**。
- 寫入只經 server action，一律先 `await requireUser()`；作者 `user.email ?? user.id`。
- 留言長度上限 `COMMENT_MAX = 2000`（DB check、純函式、textarea `maxLength` 同源）。
- `kind` 只有 `'comment' | 'resolve'`。
- Discord 回覆整則 `content.length <= 2000`；沿用 `allowed_mentions: { parse: [] }`；備註過 `neutralizeSummary`；截斷尾綴固定為 `…（全文見 dashboard）`。
- 資安留言／close 備註**永不**發 Discord。
- `pnpm test:integration` 只能對本地 stack 跑。勿跑 `pnpm dev`。
- commit 用明確路徑 `git add`，禁 `git add -A`；commit 訊息結尾 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。
- 純 UI 任務只跑 `pnpm typecheck`，不跑 `pnpm test`。

## Review Focus

1. 只含空白的備註 → 視為沒填：照常關閉、不寫留言列、Discord 回覆不帶引用區塊。（Task 1、Task 5 測試）
2. 備註含 `@everyone`、`<@123>`、`[x](http://evil)` → Discord 不 mention、`](` 被中和。（Task 4 測試）
3. 2000 字且大量換行的備註 → 每行加 `> ` 後整則仍 ≤ 2000，結尾為截斷尾綴。（Task 4 測試）
4. 按 Close 時 issue／發現已被別人改狀態（unchanged／stale）→ 不寫留言、UI 顯示「狀態已被更新」。（Task 5 測試；Task 7 action 內同規則）
5. 繞過 `maxLength` 送 2001 字備註 → 回 invalid，**狀態不轉換**（先驗證後轉換）。（Task 5 測試；Task 6/7 action 先驗證）
